# Streakly

Django-based streak tracker — gündəlik task-ları izləyib, streak-lərlə davamlılığı görünən edir.

## Features
- Task creation (recurring / one-time)
- Daily reset (local timezone)
- History & statistics
- GitHub-style activity heatmap

## Setup
\`\`\`bash
git clone <repo-url>
cd streakly
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
\`\`\`
